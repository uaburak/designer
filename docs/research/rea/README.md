# REA round — Figma's canvas reverse-engineered, and how Wecra takes it in

Written 2026-10-15. Method: Figma desktop's own cached web-editor build (the minified webpack chunks, `fullscreen-wasm` 52 MB and `prototype-lib` wasm, `timeline_renderer_worker`, render / image workers) was extracted from `~/Library/Application Support/Figma/DesktopProfile/v43/Cache` and read with [REA](https://github.com/morluto/rea) 6.5.0 (`analyze-javascript-application` per chunk), the wasm's strings (C++ class names live in its assertion and log messages; the `name` section is stripped, exports are minified) and grep around Figma's field names. Uncertain findings were probed with the Plugin API in the owner's draft "REA probe (Wecra research)" (`2Rh4mZi09rwwECJE0xBG8Z`) until the Figma MCP Starter-plan call limit stopped it — components, vector and effects got live probes, motion and canvas did not (their probe lists are in the reports, to run from the devtools console as `docs/research/figma/live/` did). Each finding carries its evidence (chunk + offset + short snippet); no Figma code is copied.

## Integration order

Ordered by correctness first, then by what the owner sees, then by size. "Batch" = one implementation round on its own branch with native tests; C++ batches end with one `npm run engine:build`.

**Batch A — correctness, small (this night's round, 2026-10-15)**
1. Vector: stroke-kind detection (`-1:-1` sentinel, neutral Dynamic = Basic), Dynamic defaults, width presets + Flip matching, kind change keeps width points / dashes, transform count 2–40, stroke settings limits.
2. Effects: glass field mapping in its seven places; tent blur + triangle-CDF analytic shadow (GL and WGSL together); asymmetric blur bounds; effect visibility rules.
3. Components: single-text rule on swap / variant switch; Push's enable rule; default property names; exposed-instance preconditions over every variant; detach `assetRef` for library mains.
4. Canvas: layout re-run after undo / redo / remote; Plugin / agent auto-layout and grid setters (SPACE_EVENLY, validation, GRID side effects); image downscale rule.
5. Motion (prototype side only — round 8 stays deferred): direction mapping, plugin `reactions` shape, timing defaults and mouse delays, easing numbers and clamps, spring settle time; `docs/motion.md` corrections.

**Batch B — Figma's rules, medium**: component validation with Figma's messages, the 15 reset kinds + plugin `removeOverrides`, variant-name backfill; per-node effect order, clamped background blur, noise / texture fBm shaders, image adjustments; Outline stroke of Dynamic / Brush, Simplify and Offset tools, scatter per-brush defaults; undo filters, edit scopes; image decode colour handling.

**Batch C — schema round (one wasm build) — done**: overrideLevel 321, overrideStash 248, componentKey 216 / sharedSymbolVersion 126 / componentPropRefs 267 on export, Paint 41 / 42, editScopeInfo 365, encodedOffsetsIndex 34, localUndoStack 22 / 23, motion fields from the current embedded schema (not the 106 dump).

  *As built (2026-10-15, finished 2026-10-19; `docs/schema.md` §15.2, native tests `engine/tests/unit/r17c.schema.test.cpp`):*
  - **overrideLevel 321** — schema, kiwi / JSON codecs and the `.fig` import keep it; override entries are keyed by `(guidPath, level)`, level 0 wins, an edit writes level 0 and leaves a deeper entry as it came.
  - **overrideStash 248** — a nested swap rewrites the stored override paths to the new main's layers, stashes what doesn't carry under `(path, old main's key)` and restores it on a swap back; the derive-time carry stays for older files.
  - **componentKey 216 / sharedSymbolVersion 126 / componentPropRefs 267** (+ `ComponentPropDef.parentPropDefId 5`) — written by Save Local Copy (`figmaExport.ts`: SYMBOL `key` → `componentKey`, a library copy's `version` → `sharedSymbolVersion`, implicit variant defs, the legacy binding list beside PROP_REF, root override path `[symbolID]`); the import maps them back. The internal model keeps `key` / `version` / PROP_REF. Our clipboard needs no mapping (Figma reads `key ?? componentKey`).
  - **Paint 41 / 42** — gradients blended in OKLab / OKLCH / HSL / linear sRGB (`render/GradientRamp`), kept by import and export.
  - **editScopeInfo 365** — kept through load, edits and save; since 2026-10-19 Figma's scope stack is in the engine (`Editor::editScopePush / Pop`, `engine_edit_scope_push / _pop`, `Engine.editScopePush / Pop`) with Figma's nesting rules, and with edit tracking on (the editor's file view) each written node is stamped with the stack it was written in — the pushed scopes, else PLUGIN for a plugin run, AI for an actor's (agent's) write, USER otherwise, labelled with the step's name; another session's changes keep their own stamp. Not done: `EditScopeSnapshot` (which field numbers each frame wrote) — nothing reads it; REST API writes are not pushed as REST_API yet (they arrive as user edits, Phase 7 round 5's path).
  - **localUndoStack 22 / localRedoStack 23** (+ `undoBatchPageIds 46`) — `engine_undo_export / _import` (the last 100 steps / 16 MB, one NODE_CHANGES Message per step); the store keeps it per device beside the file (`files/<key>/undo.kiwi`, `src/store/local/undoHistory.ts`) and the editor restores it when the journal head matches. Never in a snapshot, a version or an export; a `.fig` import drops Figma's.
  - **encodedOffsetsIndex 34** — schema only (a `.fig` import drops it: an index of one encoding is stale once re-encoded). **Skipped**: writing the index and the partial decode of unshown pages (canvas.md §2.16 step 1) — a load-time performance change in the kiwi load path, so it goes with Batch D behind `scripts/engine-bench.mjs`, not with a schema round (and the codec path was being changed in parallel).
  - **Motion fields from the current embedded schema** — the 2026-10-15 build's schema is in the repo (`docs/research/figma/figma-schema-current.kiwi`) and is now a third source of schemagen's Figma parity check; adopted with Figma's names and numbers: `TimelineData.durationUsVar 8`, `StyleIdForAnimation.timelineOffsetVar 7`, `TextElementDelayBehaviour.clipContent 5 / transformOriginMode 6 / transformOrigin 7` + `TextElementTransformOriginMode`, `AudioFill` 13–20, `AudioBeatAnalysis` + `NodeChange.audioBeatAnalyses 613`, `KeyframeValueType.ROTATION_3D 12` + `KeyframeAnyValue.rotation3DValue 12` + `Rotation3D`, `NodeContentsKeyframeBindingLocation.audioParametrizedField 5` + `AudioParametrizedField`, `Paint.videoFillPlayback 47` + `VideoFillPlayback`. They round-trip (`.fig` import, codecs, engine edits: an audio clip edit keeps the beat grid, a typed volume / offset detaches its variable); nothing draws or plays them yet (3-D rotation, beat snapping, text-stagger origins and video clips on the timeline are Motion's later increments). **Skipped**: `ExpressionFunction` 21–23 and `VariableDataType` 24–36 (incl. `UNIT_NUMBER`) — their arguments and values are types we don't carry (Paint, Length, UnitNumber, TransitionParameterValue…), so they stay dropped and counted by the import; `TransitionOverrideData` stays with transition overrides' own round.

**Batch D — performance** (gate: `scripts/engine-bench.mjs` on the owner's B2C file): lazy materialisation of invisible content, occlusion culling, time-sliced edit rendering, tile budget classes, pointer-move coalescing; then the XL threaded renderer (render worker on OffscreenCanvas) — owner's go-ahead needed, it changes `docs/engine.md` §6.

**Later, with their rounds**: Motion round 8 (keyframes through `EXPRESSION KEYFRAME`, timelines, presets as code against `figma:motion`), NUMBER / IMAGE properties and visibleWhen, slot primary instances, partial component sets on paste (multiplayer-era), StrokeAlign OFFSET / strokeData multi-stroke, glass on arbitrary shapes.
