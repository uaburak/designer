## Method

- Server: `vite --config vite.web.config.ts --mode demo --port 5891` from the main checkout (the owner's dev app on 5173 untouched; only my own server is stopped at the end). Headless Chrome for Testing 1440 x 900 (DPR 1, SwiftShader; DPR 1.5 for the canvas shots), dark theme, one browser at a time, every run under 180 s and closed in `finally`; `memory_pressure` was 37-45 % free before each run (never under 30 %). `?editor&doc=capture` for every state; `?editor&doc=components` once as a smoke check.
- Smoke: `doc=components` opens on "Sign in", Assets "4 components"; `doc=capture` Assets "5 components"; no page error, no console error in either.
- Design panel, resting: `live/tools/panel.mjs` for the 30 selection states of round 11 (page, frame, auto layout in four flavours, grid, grid child, AL child and parent, rectangle, ellipse, polygon, star, line, arrow, vector, boolean, group, text, section, image fill, component, set, variant, Button / Chip / Card instances, nested instance `I8:62;8:51`, mixed, two shapes). - Popovers: `live/tools/popover.mjs` (all 55 cases, in two runs because of its 170 s stop) plus 8 more (layer / background blur Progressive, layout guide Columns and Rows, stroke Style and Width profile lists, font picker search, and the export format menu in the cumulative Rect state).
- Menus / toolbar: the driver of round 11 (every main-menu submenu: Figma menu, File, Edit, View, View > Panels, Object, Text, Arrange, Vector, Plugins, Widgets, Preferences, Help; the nine context menus, plus a right click on an instance's Icon and its Label and on AL_vertical's title; the six bottom-toolbar dropdowns; the Actions palette and its container; the bottom toolbar; the vector edit toolbar and its More menu).
- Left side: whole-window dump for Assets (3 depths), Tools, Variables (empty on `doc=capture`, collections on `doc=variables`); left panel region for Layers hover / selected + hover, Pages add, Find and its filter menu.
- Canvas: `setCamera` + `setSelection` + hover at DPR 1.5 for 27 states, composed beside `live/img/*` (forms and presence, not the last pixel); plus the grid pill (hover, grabber click, chevron click), the grid gap hover and a gap drag, the layout guide Columns (selected and unselected), the Toolbelt modes.
- Diff: the same filtered `diff2` as round 11 (texts matched by string and nearest position, +-2 px, font, colour; controls matched by aria label, +-2 px on y / height, right edge or left edge for inputs because ours' inputs omit the prefix; DISABLED compared; live's duplicates, hidden accessibility copies, wrapper rows and `option` rows ignored). They are comparable to round 11's Appendix A-C only roughly: ours' dumps are byte-identical to round 11 for the resting states I compared (`text.txt` 101 lines in both), so a smaller count there is the tool's label filter, not a change in the app.
