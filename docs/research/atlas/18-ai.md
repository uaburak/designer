# 18 — Figma AI and Actions

Figma Design 126.9.13 (desktop), read from the cached editor build. This chapter covers how AI is reached in the Design editor (Actions, the image toolbar, context menus, the ⌘↵ agent), every AI action the build carries, what each sends, its limits and messages, how results land in the document and in undo, credits and their "out of credits" paths, errors, feature gates, the admin switches for AI and content training, and the MCP pieces of the UI. It ends with a comparison against DesignerV2's AI.

Prior work this builds on, not repeated here:
- `docs/ai.md` §1: the help-site facts (feature list, entry points, per-feature credit ranges, Skills, Connectors). Most of these hold. Where the build contradicts or sharpens them, this chapter says so.
- `docs/research/figma/R12-agents-mcp.md`: the MCP servers and tools as documented. The build confirms the desktop URL `http://127.0.0.1:3845/mcp` and the remote `https://mcp.figma.com/mcp` (§12).
- `docs/research/atlas/03-menus-shortcuts.md` §9: the Quick-actions palette (⌘K / ⌘/ / ⌘P, tabs, Recents, ranking with the 0.1 "isAI" weight, frecency). It is not repeated here; §2 adds only its AI part.
- `docs/research/figma/live/toolbar/actions-panel.txt`: the live capture of the Actions panel's AI sections.

## 4. Rename layers (`auto-rename-layers`)

Module 957010 (figma_app @2077663), C unless marked.

### 4.1 Which layers are renamed

| Rule | Value |
|---|---|
| Renamable types | RECTANGLE, ROUNDED_RECTANGLE, TEXT, FRAME, GROUP, INSTANCE. Components (SYMBOL) only when the source is Create component. |
| "Default name" test | The name matches `^<Base> [()\d]+[ ()\d]*$` (case-insensitive) for the type's bases: Rectangle → Rectangle / Image / image; Text → Text; Frame → Frame / Group; Group → Group; Polygon → Polygon / Vector; Star; Line; Ellipse; Vector; Instance. So only names with a number ("Frame 12", "Rectangle 3 (2)") count. |
| Instances | Also count as default-named when the name equals their main component's name. |
| Text | Counts when `autoRename` is still on (the name follows the content). |
| Skipped | Locked layers, layers inside instances (`isInstanceSublayer`), hidden layers and layers at opacity 0 (they are not sent at all). |
| "Rename anyway" | Re-runs with `overwriteNames` = true: every renamable layer, default-named or not. |
| Matching layers | Layers at the same path (name + index among same-named siblings, up to the top-level frame) in other selected top-level frames get the same new name, applied without animation (module 765615). |

### 4.2 Request

| Item | Value |
|---|---|
| Endpoint | `POST /api/cortex/design/editor_ai/rename_layers`, streaming |
| Body | `{nodes: [{rep, image}], isMeteringRequest: true, renameTopLayerOnly}` |
| `rep` (per node, recursive) | `name` (only when not default-named), `type` (an image-filled rectangle is sent as `IMAGE`; an instance whose main is well named is sent with the main's name as its type; a component as `COMPONENT`), `id` (only for layers to rename), `text` (characters trimmed, first 200), `autolayout` (stack mode, not GRID), `x, y, w, h` relative to the top-level layer, integers, scaled so the top layer is at most 1024 px wide, `children` (visible, opacity > 0, in panel order; not for instances) |
| `image` | A PNG data URL of each selected top-level layer: content width = min(width, 1024; for portrait layers 1024 × w / h) |
| Limit | More than **500** layers in the selection's trees → `LayerLimitExceededError`, shown as `auto_rename_layers.too_many_layers_selected` / `…too_many_layers_count` |
| Nothing to rename | `NoNameableLayersError` → `auto_rename_layers.error.no_nameable_items` with "Rename anyway". English (help): "No layers need renaming" / "Rename anyway". |
| Nothing selected | `NoSelectedLayersError` → `auto_rename_layers.select_some_layers` |

### 4.3 Stream and apply

| Item | Value |
|---|---|
| Stream | One line per layer, `"<guid>,<new name>"` |
| Validation | Unknown guids count as hallucinated and are skipped. Names holding an ordinal ("FIRST" … "TWENTIETH") or a digit are counted (`numItemsWithOrdinals`) but still applied. |
| Apply | Each name is written in an AI edit scope labelled `rename-layers` (`l7.ai`). Collapsed ancestors in the Layers panel are expanded. At the end `commit` makes the whole run one undo step (I: no merge call is used; the edit scope plus the final commit group it). |
| Animation | Per renamed layer, in the Layers panel: the old name is deleted at **0.03 s per character**, then the new name typed at **0.07 s per character**, both linear. The panel auto-scrolls to the layer being renamed. |
| Cancel / error | Every name already written is put back (with its `autoRename` flag) and the animations are cleared. Cancel = full rollback. |
| Toasts | `auto_rename_layers.renamed_n_layers`, `…missing_n_layer_names`, `…could_not_rename_all_layers`; progress `auto_rename_layers.progress`; running `auto_rename_layers.running` |
| Events | `ai_rename_layers_started / completed / cancelled / failed` with time to first token, time to completion, counts |

## 5. Text tools: Rewrite, Shorten, Translate

Shared runner: figma_app @4275500 (C).

| Item | Value |
|---|---|
| Endpoint | `POST /api/cortex/shared/adjust_text`, streaming |
| Body | `{texts: [{id, text, guid}], action, jsonMode: texts.length > 1, surroundingContext}` |
| `action` | Rewrite `{type: "REWRITE_TEXT", prompt}`; Shorten `{type: "SHORTEN"}`; Translate `{type: "TRANSLATE", language}`; Replace content `{type: "CONTENT_FILL", prompt}` |
| Ids | "1", "2", … in selection order. With one target, a missing id is allowed. |
| Targets | Text layers in the selection (unlocked; Translate / Shorten keep digits and special characters). The text-edit selection range is honoured: only the selected range is replaced. |
| Max layers | **100** text layers, else an error |
| Max characters | **40,000** in total. Above it the instruction reads `ai_text_tools.select_fewer_characters` with a "N / 40,000" counter. |
| Shorten | Exactly one text layer (`ai_text_tools.select_text_singular`) |
| Missing fonts | A layer with a missing font fails (`ai_text_tools.missing_fonts`). If every layer fails that way, the action fails. |
| Stream | Messages `{id, delta}`. On a layer's first delta its old text (or range) is cleared; each delta is spliced in at the cursor. If the user edits the layer meanwhile, the run aborts. |
| Undo | The first delta's commit is merged with the previous one under `AI_TEXT_MANIPULATION_START`, later ones under `AI_TEXT_MANIPULATION_DELTA`. The whole rewrite is one undo step. Edit scope label `adjust-text`. |
| Cancel | Restores every target's original characters and selection (`resetText`) |
| Partial failure | "N of M couldn't …" (`ai_text_tools.shorten.couldnt_count` / `rewrite.` / `translate.`) |
| Unsafe content | No Try again button |
| Events | `ai_text_tools_started / complete / failed / cancelled` with layer count, input characters, prompt length, language |

| Single-image errors | When one image was processed and it failed in a known way, a toast shows the specific message (§7.8) | 3653 @684122 | C |

### 7.2 How a result is written (module 379659, C)

Three modes:
- **APPEND**: the default for Remove background, Boost and Edit. The original image paint is **copied above itself**, the copy gets the new image, and the **original paint is disabled** (hidden, kept in the list). The new paint is selected in the Fill section.
- **REPLACE_FILL**: replaces the paint at its index.
- **REPLACE_ALL**: clears the fills and inserts the image.

Other rules:
- The change goes to every node that shares the paint data (`getMatchingNodesToUpdateForQuery(…, "fill-paint-data")`).
- Edit scope `image-modification` (AI). The commit is merged with the previous one under `AI_IMAGE_MODIFICATION`. Make an image uses `AI_GENERATE_IMAGE`, Separate object `AI_SEPARATE_OBJECT`.
- The new image's file name is `<tool> <suffix>`, e.g. `bg_removal [Background removed]`, `upscale_image [Upscaled]`.

### 7.3 Remove background

- `POST /api/cortex/design/editor_ai/clipdrop_background_removal` `{image_url}` → `{base64_image}`.
- The image URL is the image's signed URL. It is retried up to **10 × 300 ms** while it is not available yet.
- Failure: `image_ai.background_remove.failed`. Instruction `image_ai.background_remove.instruction`; `…only_one_image`.
- There is also `image_background_segmentation` (masks), used by the lasso. C.

### 7.4 Boost resolution (`upscale-image`), 3187 @5410332, C

| Rule | Value |
|---|---|
| Endpoint | `POST /api/cortex/design/editor_ai/clipdrop_upscale` `{image_url, width, height}` (each 1–4096) → `{base64_image}` |
| Input limits | The image's own pixels: > **2048** on either side → "too large" (`image_ai.upscale_image.image_too_large_error`); < **16** on either side → "too small" |
| Factor | Against the layer's on-canvas size (width / height swapped when the image is rotated 90° / 270°). ### 11.1 Requests (858 @856356, C)

| Item | Value |

## 15. DesignerV2 today

Repo: `src/shared/ai/{types,labels,prompts,schemas}.ts`, `src/main/ai/*`, `src/renderer/src/editor/ai/*` (`rename.ts`, `service.ts`, `AiPanel.tsx`), `src/renderer/src/editor/imageTools/*` (`tools.ts`, `vectorize.ts`, `runners.ts`), `src/renderer/src/editor/panels/ActionsPanel.tsx`.

### 15.1 Matches

- Action set and names (`AI_ACTION_LABEL`) and the Actions sections "Image editing / Design tools / Riffing and writing" in that order (`aiPanels.dom.test.ts`).
- Rename layers skips hidden, locked and in-instance layers; text with `autoRename` counts as default; "Rename anyway".
- Add interactions requires ≥ 2 top-level frames and writes ON_CLICK + NAVIGATE / BACK with an instant transition.
- One undo step per AI action (`writeStep` / `writeAction`). Cancel needs no rollback because nothing is written early.
- Image tools act on the topmost visible image fill. Several images are one step.
- A usage ledger shown as credits. An org AI switch (`OrgSettings.aiEnabled`).

### 15.2 Differs

| Area | Figma (this build) | DesignerV2 |
|---|---|---|
| Default-name test | `^<Base> [()\d]+[ ()\d]*$`: a number is required ("Frame" alone is **not** default). Bases include Image/image, Polygon/Vector, Star, Line, Ellipse, Instance; an instance named as its main counts. | `/^Frame( \d+)?$/` etc.: bare "Frame" counts; set of bases differs |
| Rename apply | Streamed per layer with a delete (30 ms / char) then type (70 ms / char) animation, auto-scroll; cancel rolls back the names already written. Cap 500 layers. One 1024-px PNG per top-level selection is sent along. | Applied at once after the full answer; outline capped at 400 layers per call, batched |
| Text tools | Streamed deltas into the layers, merged into one undo step; 100-layer and 40,000-character caps; text-range selection honoured; cancel restores | One-shot JSON then apply; no stated caps |
| Translate languages | The 28-language list of §5.2 (incl. Tagalog, Malay, Tamil, Urdu, English UK / US, Spanish Spain / Latin America, Portuguese Brazil / Portugal) | Own list (`TRANSLATE_LANGUAGES`, marked "[unverified]"), includes Hebrew, single "English", "Spanish", "Portuguese" |
| Add interactions | 2–10 frames; skip sources that already have a click interaction; SWAP_STATE between components / instances; OVERLAY / CLOSE; staged writing (navigate → overlays → back, 200 ms); 60 s timeout | ≥ 2 frames, no upper bound; NAVIGATE / BACK only |
| Image write mode | **APPEND**: copy the paint above, put the result there, **hide the original paint** (non-destructive) | Replaces the paint in place (`setFill` → `fills[t.index] = paint`) |
| Boost resolution | 2× or 4× of the **layer's** size (2× when below 2×), input ≤ 2048 and ≥ 16 px, "already 4×" error with "Boost anyway" (2×), output ≤ 4096 | Always ×4 of the image, long side ≤ 4096 |
| Vectorize | Server returns the vector at once; a new node `<name> [Vectorized]` at the original's index, original **hidden**; then Recolor: colours 1…detected count, grays likewise, threshold 0–1 default 0.5, Enter applies. Render 256–4096 px, ≤ 5 MP. | Settings chosen before tracing: colours 2–32 (default 8), grays 2–16 (4), threshold 0–100 (50), marked [unverified] |
| Expand | Refuses images with transparent pixels; result paint STRETCH with the engine's resized transform | Pads with transparency and re-composites the original |
| Credits | Per-action costs come from remote config per model; balances and daily / monthly summaries from the server | `creditsFor` formula of our own (`types.ts`) |
