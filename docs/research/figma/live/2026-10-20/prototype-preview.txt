Live Figma, 2026-10-20 — the inline preview (⇧Space), the presentation view and the Prototype tab
=================================================================================================
How: the owner's Drafts file "Untitled", signed in, in the app's Browser pane (Claude in Chrome was not connected),
viewport emulated at 1440 × 900 @2. A page "Proto probe (Wecra)" was made with the plugin API from the console —
"Screen A" and "Screen B" (375 × 812), a component set "Toggle" (State=Off / State=On, each On click → Change to the
other, Smart animate 0.3 s ease out), an instance of State=Off on Screen A, "Next button" (On click → Navigate to
Screen B, Smart animate), "Back button" on Screen B (On click → Back), flow "Flow 1" at Screen A; later "Desktop big"
(1440 × 1024) and "Small" (200 × 150). The page was deleted at the end; nothing else in the file was touched.
DOM read with the dump helper of docs/research/figma/live/figma-dump.js; resizes driven with synthetic pointer events
on Figma's own handles (data-testid="draggable-modal-resize-*"). Code facts from Figma's web bundle loaded by the page
(figma_app-8af2da57…, 33473-b2b1a0be…; module ids below), read in the page — no code copied.
Images: img/figma-*.jpg (live), img/wecra-*.jpg (ours before / after).

------------------------------

  corners 16 × 16 centred on the corners; cursors ns / ew / nwse / nesw.

  (h−41)/w — 234 × 361 dragged +100,+100 with ⇧ → 307 × 461 (height led), then −50,0 → 257 × 392.5; sizes not rounded.
  A top-edge drag past the minimum leaves the bottom where it was.
Drag by the header (empty part): moved freely during the drag; after it (DraggableModal ensureModalOnScreen with
  alwaysEnsureHeaderModalOnScreen + allowPartialHeaderOnScreen): top clamped to [0, innerHeight − (41 + 16)]
  (measured 843 at 900), left so that ≥ 40 px of the header stay on screen (measured −156 and 1264 kept).
Header buttons by width (1 px steps): < 153 → Preview options, Close; 153–216 → Restart prototype, Preview options,
  Open in presentation view, Close; ≥ 217 → all six.
Size and place: kept when closed and opened again in the same session (the modal is hidden with visibility:hidden,
  not unmounted); not in localStorage — a reload starts again from the default.
Initial size (bundle 33473 module 710745 `hF`/`O`, `v`, `I`, `A`, `x`, `S`; modal height = viewer + 41 (`uF` =
  40px + 1) from figma_app 342994):
  breakpoint = the page's prototype device → DEVICE at its screen size (rotated: swapped; PRESENTATION: the frame's
               size); else frame width ≥ 1280 → WEBSITE, shown at (w, w / (16/9)); else SMALL at the frame's size.
  max = (max(0.5 × canvas width, 104), canvas height − 41 − 32); min = (104, 20) (rotated device: 104 × 104).
  `A`: scale down proportionally into max; when that would put a side under its min, that side is the min and the
       other follows. `x`: then scale up to min the same way.
  Measured: 375 × 812 → 375 × 853 window; 1440 × 1024 → 450.5 × 294.5 (canvas 901 wide → 450.5; 810 × 0.3128).
Starting node (bundle 605997 / 915328): the selection's frame (getInlinePreviewNodeIdOnSelectionChange), else the
  page's active flow starting point, else the first visually sorted base screen.
Default scaling (761983): DEVICE → {fit-width, fixed}, else {scale-down-width, fixed} ("Fit width").
Keys (605997): the iframe's keydown — Shift+Space (code "Space") or Escape closes it (unless resizing / dragging),
  focus back to the canvas. The viewer's next-frame keys skip Shift+Space in the inline viewer. ← → / R as the viewer.
Selection: selecting another frame on the canvas jumps the preview there (HANDLE_EDITOR_SELECTION_CHANGED); an empty
  selection leaves it where it is; the window keeps its size.
Preview options (menu 200 wide, 24 rows, radius 13, 8 padding):
  ✓ Fit width   [24 glyph]      Fill screen [glyph]      Responsive [glyph]     (one of three)
  —
    Follow prototype            (toggle)
    Resize window to 100%       ✓ when the viewer is at the frame's 100 % size
    Reset aspect ratio          ✓ when the viewer has the frame's proportions
  Measured: Fit width at 600 wide = the frame at 100 % centred (scale-down-width); Fill screen = the whole frame
  fitted (contain, black bars, never cropped); Responsive = the frame re-laid out to the window.
  Resize window to 100%: 257 × 392.5 → 375 × 853, left / top kept (even past the window's bottom). Bundle
  710745 `N`: wider than 90 % of the canvas → a visual bell inline_preview.resize_to_actual_size_visual_bell with
  "Revert" (English text not read).
  Reset aspect ratio (`w`): the natural size, or — narrower — the current width at the frame's ratio:
  475 × 1148 → 375 × 853; 175 × 853 → 175 × 420.
  Follow prototype: the canvas pans and zooms to the frame the preview shows (zoom 0.6, centred on it); the canvas
  selection is NOT changed. Logged as prototype.frame_following_selection_replaced.
Live: Change to on the Toggle instance played inside the preview (Smart animate).
