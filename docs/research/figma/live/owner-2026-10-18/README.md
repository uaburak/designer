# Owner's captures, 2026-10-18 (Figma desktop 126.x vs Wecra, same machine)

Taken by the owner side by side to show what the first comparison missed. `figma-*` are Figma, `wecra-*` are ours.

- **Dev Mode** — `figma-devmode-inspect` vs `wecra-devmode-inspect`: Figma's left panel (Pages, "Ready for development" with Mark as ready for dev, Layers), the canvas with padding / gap measurements (hatched areas, blue number pills, pink gap hatch), the right panel Inspect | Plugins with the selection header, MCP section (Selection details, Session activity, Estimated tokens, prompt box, Copy example prompt), Code Connect, Layer properties box model (Border / Padding / size, border-box), List | Code toggle, CSS select, Layout code with line numbers.
- **Motion** — `figma-motion-timeline-headline`, `figma-motion-rect-gizmo-panel` vs `wecra-motion-canvas-timeline`: the canvas transform gizmo (anchor circle with a green up arrow and a pink right arrow, dotted guides to the frame edges), the right panel header "Motion Beta" + zoom, Animations / Transform (X→ Y↓, ↔ ↕ %, rotation, anchor button) / Layout / Appearance / Fill with diamond buttons at the right of each field, the timeline (header: play, keyframe, "1855 2000 ms", loop; rows with ‹ ◇ › and the current value; ruler "0s 500ms 1s 500ms 2s"; clip bars; diamonds).
- **Glass** — `figma-glass-panel-design`, `figma-glass-stripes-*`, `figma-glass-depth1-zoom423`, `figma-glass-depth100-zoom423`, `figma-glass-on-white-depth100`, `figma-glass-frost23`, `figma-glass-zoomed-out-page-panel` vs `wecra-glass-panel`, `wecra-glass-stripes-*`: the effect's look at the same settings (a 100×100 circle, corner 126.5, fill D9D9D9 20 %, over blue / red / green / yellow stripes; Light −45° 80–100 %, Refraction, Depth, Dispersion, Frost, Splay), and the settings popover (light dial, sliders with a blue filled track and a white knob, value fields).
- **Effects** — `figma-effects-add-menu`: "+" opens a menu (Inner shadow, Drop shadow, Layer blur, Background blur, Noise, Texture, Glass, a separator, Shader Beta); `figma-shader-pixelate-panel`: a shader's popover.
- **Boolean menu** — `figma-boolean-menu`: Union ⌥⇧U, Subtract ⌥⇧S, Intersect ⌥⇧I, Exclude ⌥⇧E, Flatten ⌥⇧F, Edit object, with Figma's icons.
