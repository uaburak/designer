## 1. The model: reactions, triggers, actions

- A reaction = one trigger + a list of actions (`actions[]`; the single `action` field is the older shape). `reactions` is read-only when the manifest uses dynamic-page access; write with `setReactionsAsync`. — official, https://developers.figma.com/docs/plugins/api/properties/nodes-reactions/
- Trigger types (typings): `ON_CLICK`, `ON_HOVER`, `ON_PRESS`, `ON_DRAG`, `ON_MEDIA_END` (no fields); `AFTER_TIMEOUT {timeout ms}`; `MOUSE_UP` / `MOUSE_DOWN {delay ms}`; `MOUSE_ENTER` / `MOUSE_LEAVE {delay ms, deprecatedVersion}`; `ON_KEY_DOWN {device KEYBOARD|XBOX_ONE|PS4|SWITCH_PRO|UNKNOWN_CONTROLLER, keyCodes[]}`; `ON_MEDIA_HIT {mediaHitTime}` (seconds). `ON_HOVER` and `ON_PRESS` revert navigation when the trigger ends; MOUSE_* are one-way. — official, https://developers.figma.com/docs/plugins/api/Trigger/
- Action types: `BACK`, `CLOSE` (topmost overlay), `URL {url}` (named "URL" in typings; the new-tab option is only in prose), `UPDATE_MEDIA_RUNTIME` (PLAY, PAUSE, TOGGLE_PLAY_PAUSE, MUTE, UNMUTE, TOGGLE_MUTE_UNMUTE; SKIP_FORWARD/SKIP_BACKWARD with `amountToSkip` s; SKIP_TO with `newTimestamp` s; `destinationId` null = the node itself), `SET_VARIABLE {variableId, variableValue}`, `SET_VARIABLE_MODE {variableCollectionId, variableModeId}`, `CONDITIONAL {conditionalBlocks[{condition?, actions}]}` (no condition = else), `NODE {destinationId|null, navigation NAVIGATE|SWAP|OVERLAY|SCROLL_TO|CHANGE_TO, transition|null, preserveScrollPosition?, overlayRelativePosition? (OVERLAY+MANUAL only), resetVideoPosition?, resetScrollPosition?, resetInteractiveComponents?}`; `destinationId` is null when the target was deleted/invalid. — official, https://developers.figma.com/docs/plugins/api/Action/
- Expression functions (typings): ADDITION, SUBTRACTION, MULTIPLICATION, DIVISION, EQUALS, NOT_EQUAL, LESS_THAN(_OR_EQUAL), GREATER_THAN(_OR_EQUAL), AND, OR, VAR_MODE_LOOKUP, NEGATE, NOT; arguments are nested `VariableData` (BOOLEAN, FLOAT, STRING, VARIABLE_ALIAS, COLOR, EXPRESSION, EASING, TIMING). — official, same page.
- One object may hold any number of Key/Gamepad, On drag and When video hits triggers; only one each of the other trigger types (On click, While hovering, After delay …). On click cannot be combined with While hovering on one object (use Mouse enter/leave). — official, CONN https://help.figma.com/hc/en-us/articles/360040315773
- Trigger behaviour: On drag moves through the transition as a continuum, four directions; While hovering returns to the original frame when the cursor leaves; While pressing returns on release; Mouse enter/leave fire only on the first enter/exit since 2023-11-16 (older ones show as "Mouse move inside/outside" and cannot be created); Mouse down/up = touch down/up on mobile; After delay in ms; When video hits with a timestamp past the end fires at the end; Key/Gamepad officially Xbox One, PS4, Switch Pro (others may mislabel buttons). — official, TRIG https://help.figma.com/hc/en-us/articles/360040035834
- Multiple actions: unlimited on one trigger; run top to bottom in listed order (a Conditional sees a variable set by the action above it); multiple animations run sequentially; any action can be dragged into a Conditional; invalid conditions are outlined red; whether conditionals nest is not documented. — official, MULTI https://help.figma.com/hc/en-us/articles/15253220891799
- Actions notes: Scroll to — the panel picker lists only direct children of scrollable frames, a dragged noodle can target any object in the same top-level frame, Instant or animated, a destination hidden by a clipped frame needs Clip content off. Open link — new tab; external sites show a leaving-Figma notice with a "don't show again" checkbox stored per device. Swap overlay from a normal frame behaves like Navigate to; from an overlay it replaces it, keeps its settings and is not recorded in history. Change to on a nested instance can change the parent component's variant. — official, ACT https://help.figma.com/hc/en-us/articles/360040035874
- Variables in prototypes: types string, number, boolean, color; Set variable's value must match the type (quoted strings, true/false, hex or picker colours); bindable: text content (string), width/height/corner radius/auto-layout properties (number), visibility (boolean), variant and component properties. Scope follows where the variable is bound: a variant property on an instance changes only that instance; a component property updates every instance. — official, VARP https://help.figma.com/hc/en-us/articles/14506587589399
- Connections UI: multi-select hotspots then drag one plus to create one interaction each; select several connections to retarget at once; matching interactions (same action + destination from same-name, same-hierarchy objects) can be selected together and the canvas draws only the top-left one; interaction details can be copied/cut/pasted with Cmd/Ctrl+C/X/V; Shift hides the details panel from the canvas. — official, CONN.

## 2. Transitions and easing

- Types: Instant; Dissolve; Smart animate (Easing+Duration); Move in/out (destination slides over a stationary original), Push (original pushed out, mimics a swipe), Slide in/out (destination moves while dissolving, the original is offset too) take Direction+Easing+Duration. Typings: `SimpleTransition` (DISSOLVE | SMART_ANIMATE | SCROLL_ANIMATE) and `DirectionalTransition` (MOVE_IN | MOVE_OUT | PUSH | SLIDE_IN | SLIDE_OUT, `direction` LEFT|RIGHT|TOP|BOTTOM, `matchLayers` boolean), each with `easing` and `duration`. — official, ANIM https://help.figma.com/hc/en-us/articles/360040522373 and https://developers.figma.com/docs/plugins/api/Transition/
- `duration` unit in the Plugin API is not stated on the typings page; REST uses ms; plugin authors and our agents' tool use seconds (0.3). Treat as seconds. — community/inference.
- Duration range 1–10 000 ms. — official, CONN.
- Easing names: Linear, Ease in, Ease out, Ease in and out, Ease in back, Ease out back, Ease in and out back, Custom bezier (`cubic-bezier(x1,y1,x2,y2)`, endpoints fixed 0,0 / 1,1, the curve may leave the graph for overshoot; custom curves cannot be saved, only copy/pasted); springs Gentle, Quick, Bouncy, Slow, Custom spring. Typings: `CUSTOM_CUBIC_BEZIER` with `easingFunctionCubicBezier{x1,y1,x2,y2}`, `CUSTOM_SPRING` with `easingFunctionSpring{mass,stiffness,damping,initialVelocity}`. — official, EASE https://help.figma.com/hc/en-us/articles/360051748654 and Transition typings.
- Custom spring UI: Stiffness ≈ number of bounces, Damping ≈ springiness, Mass ≈ speed and bounce height; changing mass changes the shown millisecond duration (derived). — official, EASE.
- Spring design: defined by mass/stiffness/damping and solved with WebKit's SpringSolver; the editor reduces them to two handles (horizontal = speed from mass/stiffness, i.e. period; vertical = overshoot from the damping ratio) plus a duration handle marking where the animation is cut off. No preset numbers published. — official, https://www.figma.com/blog/how-we-built-spring-animations/
- Preset numbers are on no official page. Atlas 13 §5.4 (bezier table; Gentle 1/100/15, Quick 1/300/20, Bouncy 1/600/15, Slow 1/80/20; stored durations 1.022 / 0.744 / 0.958 / 1.250 s) come from Figma's shipped code. — our REA, not web.
- `initialVelocity` exists only in the API, not the UI. — official, Transition typings.

## 3. Smart animate

- Matching: layer name plus position in the hierarchy, for layers that exist in several frames. Duplicating a frame keeps names; hovering a layer in the Prototype tab highlights its matches; a group with a unique name un-matches its content; whole objects, components and layers inside components/groups can match. Top-level frame names need not match, parents' names do. — official SA https://help.figma.com/hc/en-us/articles/360039818874 ; top-level detail community, https://forum.figma.com/t/what-are-the-layer-matching-rules-of-smart-animate/5935 (seen only via search snippet).
- Animates: scale (size), position, opacity (set layer opacity to 0, do not hide), rotation (a group can rotate about an anchor), fills (solid ↔ gradient ↔ image), effects texture, noise, background blur, layer blur. Does not animate: drop shadow, inner shadow, moving between different shapes. A frame with an unsupported property falls back to a default dissolve. — official, SA.
- New layers in the destination dissolve in; identical layers do not animate. Overlay actions never smart-animate (new frame); Swap overlay with matching layers does. — official, SA.
- "Animate matching layers" on Move/Push/Slide: non-matching layers use the main transition, matching ones smart-animate, matching Fixed layers get no transition, non-matching Fixed layers dissolve; layers above matching layers animate above the destination; the frame's own fill is not animated so overlaps show (add a filled rectangle behind). — official, SA.
- The help page says nothing about auto layout, text content, corner radius, strokes or constraints. Community: names that follow text content can break matching (hard-name text layers), different vector shapes only dissolve, overridden/nested instances and variable-driven nested state changes are unreliable (reports 2021–2026, no Figma explanation). — community, https://forum.figma.com/t/smart-animate-when-using-component-overrides/261 , https://forum.figma.com/ask-the-community-7/i-applied-smart-animate-but-it-only-dissolves-12539 , https://forum.figma.com/t/nested-animation-stops-when-using-variables/64046/6 . Treat as bugs/limits, not features to copy.
- Our reverse engineering (atlas 13 §5.5) is stronger: corner radii, stroke weight and paints, text-decoration paints, effects interpolate; identity is path + same-name sibling index.
- The 2024-05-01 Skew→TypeScript migration caught a Smart animate regression caused by devirtualisation differences, and fixing array destructuring cut per-frame latency by up to 25 %: Smart animate runs in the viewer's own code. — official, https://www.figma.com/blog/figmas-journey-to-typescript-compiling-away-our-custom-programming-language/

## 4. Flows, connections, settings

- A connection has hotspot (frame or object), noodle, destination (normally a top-level frame; only Scroll to may target inside the same top-level frame). — official, CONN.
- Device settings (select nothing, Prototype tab): Device = Frame preset (auto-matched) / Custom Size (Fit) / Presentation (Full); Orientation Portrait/Landscape (presentation view only; cannot change within one prototype); Model (colour variants; iPhone 15 Pro Max has four); Background colour (presentation view only). Inline preview offers only phone/watch/tablet presets and shows no device for Custom Size/Presentation; computers excluded because of size. Defaults not documented. — official, DEV https://help.figma.com/hc/en-us/articles/21158597546391 and https://www.figma.com/blog/behind-the-feature-inline-device-frames/
- Device frames are SVG artwork; 50 hit-target SVGs, one per device (bezel drag area vs a 16 px resize edge; e.g. the dynamic island is excluded so it never blocks taps). — official, same blog.
- Starting points: restart returns to the current flow's start, without flows to the first canvas frame; without flows, frames are ordered by x then y, and when connections exist only connected frames are shown. — official, PLAY https://help.figma.com/hc/en-us/articles/360040318013

## 5. Overlays

- Any object/group/frame can trigger; the overlay frame must be a frame on the canvas. Settings live on the overlay frame, not the connection (reused by every interaction). Seven preset positions or manual; optional background (colour + opacity) between overlay and the frame beneath; "Close when clicking outside"; animation transition/direction/easing/duration. — official, OVL https://help.figma.com/hc/en-us/articles/360039818254
- Swap overlay keeps position (cannot change it), is not in history; Back after a swap returns to the previous screen. Overlays are edited/removed only in Prototype mode (blue icon beside the frame, hotspot, or arrow); remove by dragging the arrow to empty canvas, selecting the overlay and Delete, or right-click connection → Remove all interactions. GIFs are static in the editor and play in presentation. — official, OVL.
- Not documented: stacking of several overlays, scrolling inside overlays, whether Navigate to closes overlays (R8 / atlas 13 hold that it does, from code).

## 6. Scroll behaviour

- Overflow (frames only, any nesting): No scrolling, Horizontal, Vertical, Both; content must exceed the frame (else a warning); "Clip content" hides overflow on canvas; resizing with Cmd/Ctrl held ignores constraints/auto-layout sizing so content can be extended. — official, SCR https://help.figma.com/hc/en-us/articles/360039818734
- Position: Scroll with parent, Fixed (moved above other layers, labelled "Fixed" in Layers; scrolling objects cannot go above it; in auto layout only when absolute positioned), Sticky (vertical-scrolling frames only; pins when its top reaches the parent's top; bounded by its direct parent; layers below scroll behind it, above scroll in front). Canvas stacking "Last on top" (default) / "First on top" in auto layout. — official, SCR.
- Scroll position is preserved automatically between top-level frames with identical names or the same prefix before " / "; new-style interactions share scroll state between matching named objects; "Reset scroll position" is per interaction. Interactions made before 2023-05-24 are legacy ("Preserve scroll position", upgrade via Update / Update all). — official, STATE https://help.figma.com/hc/en-us/articles/14397859494295

## 7. State management

- Memorised on return: interactive component variants, scroll position, video play state. Shared between matching objects across frames (same layer name + same parents; top-level frames matched by identical name or common prefix before "/"); component state is shared only after the component was interacted with at least once. Reset is per interaction (Reset scroll position / Reset component state / Reset video state), shown only when relevant; defaults undocumented. — official, STATE.

## 8. Interactive components

- Change to links only variants of the same component set; created by dragging from the variant's bounding box to the destination variant, or Action → Change to. Instances carry the variant interactions automatically; overrides on the default variant are preserved under the normal override rules; overrides on non-default variants do not show in presentation view. — official, IC https://help.figma.com/hc/en-us/articles/360061175334
- The Prototype tab shows "Interactions" and "Variant interactions"; an instance can override a variant interaction; the main component's interactions are edited in the source file ("Go to main component"). — official, IC.
- Same trigger on an instance: the instance's own interaction is used and the variant interaction is ignored; different triggers: both play. — official, IC. (Atlas 13 §10.8 reads a code tooltip as "instance interactions run before inherited ones" — see differences.)
- A variable bound to a variant property: clicking updates both variant and variable. A variant change that alters a font setting can make the viewer substitute Inter when text overrides cannot be kept. — official, IC.

## 9. Presentation view and inline preview

- Inline preview: Preview button, a flow's play icon, or Shift+Space; arrows (back/forward), Restart (R, from the last selected canvas frame), overflow menu (Fit width, Responsive, Follow prototype, Resize window/device to 100%, Respect aspect ratio, Show device frame), open in presentation in a new tab; edge-resize (Shift keeps ratio); live edits; clicking a frame on canvas jumps to it. — official, PLAY.
- Presentation: Present = Cmd+Option+Return / Ctrl+Alt+Enter. Toolbar left: logo, flows sidebar (flows + descriptions), comment mode; right: spotlight/presenter, Share, options menu, full screen. Bottom: ← →, device switcher (only with a device), Restart. — official, PLAY.
- Options menu: Enable Figma shortcuts, Show hints on click, Make available offline, Accessibility settings, Hide UI (`&hide-ui=1`); scaling without device — Actual size (100%), Responsive, Fit width, Fit width and height (never scales up), Fill screen; with device — Responsive, Fixed size, Fit device on screen, Zoom device to fill screen, Show device at 100%, Show device frame. Keys: → / Space / N next, ← previous, R restart, Z cycle scaling, C comments, F full screen (C and F need shortcuts enabled). Default scaling: first frame > 1024 px → Actual size (Responsive suggested); < 1024 px → Actual size (Fit width and height suggested); all frames 16:9 or device Presentation → Fill screen; Custom device → Fit width and height. — official, PLAY.
- Hints: clicking off a hotspot flashes blue boxes on clickable areas. — official, PLAY.

## 10. Architecture (what is public)

- The prototype viewer is separate from the editor: Skew (a compile-to-JS language) was written to build it for web and mobile because mobile browsers could not take the C++/Wasm engine at first. Skew was fully replaced by TypeScript by 2024-05-01; hot paths such as file loading were replaced by the C++ engine's components; a 2020 benchmark showed prototype loading nearly 2× slower in plain TypeScript on Safari before that. — official, https://www.figma.com/blog/figmas-journey-to-typescript-compiling-away-our-custom-programming-language/ (2024-05-01)
- Public numbers: 50 device hit-target SVGs; 16 px resize edge; duration cap 10 000 ms; video ≤ 300 MB, MP4/MOV H.264 or WebM VP8 (R8 §13).
- Nothing public found about WebGL/WebGPU in the viewer, frame derivation, or how the viewer receives the document. Atlas 13 §12 (REA: prototype-lib wasm doing matching/planning, JS viewer classes for transitions) is our only source. — gap

## Differences to check in Wecra

1. **Instance vs inherited interaction on the same trigger.** Help (official): the instance's interaction wins, the variant/main one is ignored; atlas 13 §10.8 (code tooltip): both exist, instance first. Test what our player runs; if both run, change to "instance wins, main ignored" unless a probe of the real viewer says otherwise.
2. **Trigger exclusivity.** One object: one of each non-repeatable trigger; On click and While hovering may not coexist; Key/Gamepad, On drag, When video hits may repeat. Check the panel's "already used" logic also blocks click + hover.
3. **After delay maximum.** Web says only "ms"; R8 forum 10 000; atlas 13 code 20 s. Keep 20 s and make sure agents' tools accept it.
4. **Mouse enter/leave** fire only on first enter/exit (since 2023-11-16); legacy move-inside/outside only read from old files. Check we neither repeat-fire nor allow creating the legacy kinds.
5. **Matching-interaction grouping**: selectable together, only top-left noodle drawn; interaction copy/paste (Cmd/Ctrl+C/X/V); Shift hides the details panel on canvas. Verify each exists.
6. **Overlay deletion**: drag noodle to empty canvas, Delete on the overlay frame, right-click connection → Remove all interactions; blue overlay icon opens settings; overlays editable only in Prototype mode.
7. **Open link notice**: external links show a leaving-Figma notice with a per-device "do not show again"; new tab. Check the viewer has it.
8. **Scroll to**: picker lists only direct children of scrollable frames; any object via noodle; same top-level frame only; consider a warning when a clipped frame hides the target.
9. **Fixed/Sticky**: Fixed layers re-ordered above and labelled "Fixed" in Layers, scrolling layers cannot be placed above them, Fixed in auto layout only when absolute; Sticky only in vertical-scroll frames, bound by direct parent (atlas 13 §14 flags the nested rule).
10. **State sharing**: component state shared across frames only after the component was interacted with; top-level frames match by identical name or common prefix before "/".
11. **Smart animate**: nothing official on text, corner radius, strokes, auto layout; keep atlas 13 §5.5. Do not copy community bugs (nested overrides, text named after its content).
12. **Springs**: no official table; keep Gentle 1/100/15, Quick 1/300/20, Bouncy 1/600/15, Slow 1/80/20; custom spring shows Mass/Stiffness/Damping and a derived duration; `initialVelocity` only in the API.
13. **Plugin API shapes our agents emit** (`agents/prototypeSpec.ts`): action type `URL`; `NODE.navigation` includes `CHANGE_TO`; `overlayRelativePosition` only for OVERLAY+MANUAL; `destinationId` null for deleted targets; `UPDATE_MEDIA_RUNTIME` seconds fields (`amountToSkip`, `newTimestamp`); `MOUSE_ENTER/LEAVE` carry `deprecatedVersion`; `ON_MEDIA_HIT.mediaHitTime`; conditional block without condition = else; expression/variable data may be EASING or TIMING.
14. **Device options**: Custom Size (Fit) and Presentation (Full) only in presentation view; inline preview only phone/watch/tablet; orientation presentation-only and one per prototype; Background presentation-only.
15. **Presentation defaults and chrome**: scaling thresholds (1024 px, all-16:9, Custom device); Restart to the current flow's start or first canvas frame; "Make available offline" and "Accessibility settings" menu entries (likely gaps); Hide UI adds `hide-ui=1`.
16. **Shortcuts**: Space and N advance as well as →; C and F need "Enable Figma shortcuts"; Z cycles scaling (atlas 13 open question 9).
17. **Variables in prototypes**: bindable set is text, dimensions, corner radius, auto-layout properties, visibility, variant/component properties; colour bindings not listed by help; typed Set variable values (quoted strings, true/false, hex).
18. **Not on the web, keep reverse-engineered**: overlay stacking, Navigate to closing overlays, overlay/scroll interplay, viewer renderer, document delivery. Atlas 13 §15 probes remain the way to settle them.
