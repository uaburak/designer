Install on a Mac

  1. Open the downloaded .dmg file.
  2. Drag Wecra into Applications.
  3. Open Wecra from Applications or Launchpad.

Install on Windows

  1. Run the downloaded Setup .exe file.
  2. Follow the installer.
  3. Open Wecra from the Start menu.

Updates

Wecra downloads new versions by itself. Choose Restart to update when it offers, or the update installs the next time you quit. What changed in each release is in the changelog.
