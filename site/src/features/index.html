Features

Everything a design file needs.

Wecra works the way Figma does: the same tools, the same panels, the same words. Here is the editor, one part at a time.

Frames and auto layout

Layouts that adjust themselves.

Draw a frame, press Shift A, and its children line up. Change direction, gap and padding; frames hug their content or fill their parent.

  • Horizontal, vertical, wrap and grid
  • Hug, fill and fixed sizes, with min and max
  • Constraints, sections and groups
The pen and vectors

Draw any shape.

The pen draws vector networks with real handles. Booleans stay live, so you can still edit what you combined.

  • Pen, pencil, polygon and star
  • Union, subtract, intersect and exclude
  • Flatten, masks, gradients and image fills
Components and variables

Build once, use everywhere.

Components, variants and properties, with overrides that survive updates. Variables with modes switch a whole frame from light to dark.

  • Boolean, text, instance swap and variant properties
  • Collections, modes, aliases and scopes
  • Color, text, effect and grid styles
Prototyping and presenting

Click through it before you build it.

Connect frames with interactions and play the flow in presentation view, the way it will feel on a phone.

  • Flows with starting points
  • Interactions and transitions
  • Presentation view
Dev Mode

Hand off without the back and forth.

Switch on Dev Mode and select any layer: its size, its spacing on the canvas and its CSS, ready to copy.

  • Measurements between layers
  • Code for the selection
  • Developer previews you can share as a link
Libraries

One source for every file.

Publish components, styles and variables from any file. Files that use them get the update and accept it when they're ready.

  • Publish with a list of what changed
  • Review updates side by side
  • Update selected or all

Try it on your own files.
