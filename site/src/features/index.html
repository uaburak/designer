Features

Everything a design file needs.

Wecra works the way Figma does: the same tools, the same panels, the same words. Each card below is the app itself, drawn with its own components.

The pen and shapes

A pen that feels right.

Click for corners, drag for curves, and the pen draws real vector paths with handles.

Home

Your files, in order.

Drafts, folders, Recents, Starred and Trash, like the file browser you know. Files live on your computer, and search finds them as you type.

Teams and organizations

A shared workspace, with the controls you need.

Each team keeps its projects together, and everyone on it can open them. Give people a role on the team, admin, can edit or can view, or just on one folder or file. Share a file by email or by link, and work in it together, live.

In an organization, members log in with SAML SSO from Okta, Microsoft Entra ID or another provider, SCIM keeps them in step, and guests can be required to use two-factor authentication. Admins manage people, teams, link sharing and guest access, and see every change in the activity log.

Components and variants

Build it once.

Make a component, add variants for each state, and expose its label and icon as properties. Change the main component and every instance follows.

Variables and modes

One value, every mode.

Keep colours, numbers, strings and booleans as variables, with a value for each mode. Switch a frame to Dark and everything bound to them updates.

Comments

Feedback, in place.

Pin a comment to the exact spot, reply in a thread, and resolve it when it’s done. Everyone who opens the file sees the same conversation.

Libraries

One system, every file.

Publish components, styles and variables from any file and use them everywhere. When the library changes, review the update and accept it.
