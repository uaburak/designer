The pen and shapes

A pen that feels right.

Click for corners, drag for curves, and the pen draws real vector paths with handles. Sketch with the pencil, drop a star, then give it a fill and a stroke. The canvas here is the Wecra engine itself.

Components and variants

Build it once.

Make a component, add variants for each state and size, and expose its label and icon as properties. Change the main component and every instance follows.

Variables and modes

One value, every mode.

Keep colours, numbers, strings and booleans as variables, with a value for each mode. Bind them to your layers, switch a frame to Dark, and everything bound to them updates.
